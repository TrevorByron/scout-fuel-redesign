# Style template

This folder contains the active Glass style used by the app.

## File

- **style-glass.css** – Glass / frosted visual treatment and token values.

## Customizing

Edit `style-glass.css` to tweak tokens and component-specific styles.

The file defines:

1. **Swatch variable** – `:root { --swatch-glass: ... }`

2. **Light theme** – `html[data-style="glass"] { ... }`

3. **Dark theme** – `html[data-style="glass"].dark { ... }`
